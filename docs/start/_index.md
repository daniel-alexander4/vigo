# Tutorials

Learning-oriented, hands-on. One golden path that takes you from nothing to a converging, compliance-reporting fleet. Work through them in order — each builds on the last. (Looking for a specific task instead? See the [how-to guides](../howto/).)

1. [**Stand up the server**](stand-up-the-server.md) — run vigosrv, log in, and enroll the server's own envoy over loopback.
2. [**Enroll your first envoy**](enroll-your-first-envoy.md) — mint a token, install the agent, watch the first check-in land.
3. [**Your first configcrate**](your-first-configcrate.md) — write a small configcrate, `config publish` it, and watch it converge on the dashboard.
4. [**Your first compliance report**](your-first-compliance-report.md) — point a framework at the fleet, read the coverage, and export your evidence.
