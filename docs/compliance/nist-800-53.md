# NIST 800-53 Compliance

NIST SP 800-53 defines security and privacy controls for federal information systems. It's the foundation for FedRAMP authorization. Vigo enumerates the full **287-control Moderate baseline** (per NIST SP 800-53B) across all 20 control families, with explicit per-control scope tagging so an auditor can see which controls Vigo enforces, which it attests to, and which require uploaded documentation.

NIST 800-53 is U.S. Government work product (public domain); full control titles are reproduced verbatim from the catalog.

## Coverage Summary

All families are enumerated. Family-level scope distribution at a glance:

| Family | Name | Predominant scope |
|--------|------|-------------------|
| AC | Access Control | enforced |
| AT | Awareness and Training | documented |
| AU | Audit and Accountability | enforced (review attested) |
| CA | Assessment, Authorization, Monitoring | documented (CA-7 attested) |
| CM | Configuration Management | enforced |
| CP | Contingency Planning | documented (backups/recovery enforced) |
| IA | Identification and Authentication | enforced |
| IR | Incident Response | documented (IR-5/IR-6 attested) |
| MA | Maintenance | documented |
| MP | Media Protection | documented (MP-6 sanitization enforced) |
| PE | Physical and Environmental Protection | documented |
| PL | Planning | documented |
| PM | Program Management | documented |
| PS | Personnel Security | documented |
| PT | PII Processing and Transparency | documented |
| RA | Risk Assessment | documented (RA-5 attested) |
| SA | System and Services Acquisition | documented |
| SC | System and Communications Protection | enforced |
| SI | System and Information Integrity | enforced (SI-4/SI-5 attested) |
| SR | Supply Chain Risk Management | documented |

## Quick Start

```bash
cp example-configs/stockpile/modules/compliance/nist-800-53/*.vgo.example /srv/vigo/worksite/stockpile/modules/
for f in /srv/vigo/worksite/stockpile/modules/nist-*.vgo.example; do mv "$f" "${f%.example}"; done
cp example-configs/stockpile/compliance-roles.vgo.example /srv/vigo/worksite/stockpile/compliance-roles.vgo
```

Assign the `nist-800-53` role to nodes:

```yaml
envoys:
  - match: "*.example.com"
    roles: [nist-800-53]
```

Then publish and verify: `vigocli config publish && vigocli report nist`

## Generating Reports

```bash
vigocli report nist
vigocli report nist --format html --output nist-report.html
```
