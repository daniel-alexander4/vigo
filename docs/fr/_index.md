# Documentation Vigo

Cette documentation s'adresse aux opérateurs — la personne qui installe Vigo, enrôle les Envoys, écrit des configcrates, publie des changements, exécute Scrier, produit des rapports de conformité et débogue lorsqu'un problème survient.

**Nouveau ici ?** Lisez la [présentation de Vigo](overview.md) pour comprendre ce que fait la plateforme, puis suivez le [démarrage rapide](quickstart.md) — serveur lancé, premier Envoy enrôlé, premier configcrate appliqué, en dix minutes de copier-coller. À partir de là, choisissez un parcours :

| | |
|---|---|
| **Démarrer** | [Tutoriels](start/) — le chemin idéal : mettre en place le serveur, enrôler un Envoy, livrer votre premier configcrate, exécuter votre premier rapport de conformité |
| **Réaliser une tâche** | [Guides pratiques](howto/) — configcrates, Swarm, authentification, surveillance, conformité, sauvegarde/reprise après sinistre, migration depuis un autre CM |
| **Rechercher une information** | [Référence](reference/) — commandes vigocli, ressources de l'agent, traits de l'agent, API REST, server.yaml, le langage configcrate, la matrice de conformité |
| **Comprendre le pourquoi** | [Concepts](concepts/) — architecture, convergence vs conformité, le Swarm, l'identité Puddle, le modèle de sécurité |
| **Voir des exemples** | [Exemples de configcrates](examples/) — configcrates de bout en bout couvrant les schémas courants |
| **Définir un terme** | [Glossaire](glossary.md) |

Le public visé est l'opérateur. Les justifications internes destinées aux ingénieurs résident dans les ADR et le code source ; les contenus marketing se trouvent sur vigo-web.
