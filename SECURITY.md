# Security

## Reporting a vulnerability

Email vigo.support@alexander4.io with "SECURITY" at the start of the subject
line. Please do not open a public GitHub issue for a vulnerability.

Include the Vigo version, what you found, and the steps to reproduce it. We
reply within 2 business days to confirm we have the report, and keep you
informed until it is fixed.

## Disclosure

We fix the vulnerability, ship a new release and then publish an advisory on
the GitHub repository. We aim to publish within 90 days of the report, and
sooner when a fix is ready. We credit reporters in the advisory unless they
ask us not to.

Premium support customers receive private notice of the fix 7 days before the
public advisory. See [SUPPORT.md](SUPPORT.md).

## Supported versions

Security fixes ship in a new release and are not backported. Support covers
the latest release and any release from the previous six months; see
[SUPPORT.md](SUPPORT.md#supported-versions).
