# Support

Vigo is free software under the [Apache License 2.0](LICENSE). Anyone can run
it, at any size, with no license fee. Alexander4, LLC also sells support
subscriptions to organizations that need a vendor of record, defined response
times and help running Vigo in production. One subscription covers both Vigo
and Connwaer.

## Community support

Free for everyone. Open an issue on GitHub or email
vigo.support@alexander4.io. Answers are best effort, with no response time
and no obligation.

Business hours are 8am to 5pm Pacific time, Monday to Friday, excluding US
federal holidays. A response time is the time from when we receive a ticket
to when an engineer replies to it.

Premium service credits apply when a production-down response is late. Each
late response earns a credit of 2% of the annual fee, up to 10% of the annual
fee per year. Credits are applied to the next invoice.

There is no 24/7 support package.

### Severity

- **Production down.** The Vigo server is unavailable, or agents cannot
  converge across a significant part of your production fleet, and there is no
  workaround.
- **Degraded service.** Vigo works, but a production function is impaired, or
  a workaround exists.
- **Everything else.** Questions, configuration guidance, minor bugs and
  feature requests.

You set the severity when you open a ticket. We may change it if the ticket
does not match the definition, and we will tell you when we do.

### What support covers

Configuration guidance, bug triage and fixes, and upgrade help for Vigo and
Connwaer. It does not cover writing your configcrates, managing your
infrastructure, or general systems administration. Custom development is
available as a separate engagement, quoted on request.

Feature requests are welcome from every customer. We review them and decide
what to build; no package guarantees a feature or a date.

### Supported versions

Support covers the latest release and any release from the previous six
months. Fixes ship in a new release and are not backported. If you are on an
older release, the first step is an upgrade, and we will help you plan it.

### Nodes

A node is a machine running the Vigo agent or the Connwaer agent and enrolled
with your Vigo servers. A machine running both counts once. You report your
node count when you buy and again at each renewal, and the fee for the coming
year is based on that count.

### If we stop providing support

The code is Apache-2.0, so you keep every release you have and can run,
change and maintain it yourself. If Alexander4 stops providing support during
your term, we refund the unused part of your annual fee.

## Buying support

count. Paid support is provided under a written agreement, invoiced annually
in advance, and payable by purchase order on net 30 terms.
