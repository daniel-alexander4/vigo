<objective>
Add conditional fields to module references in roles and clients.yaml so admins can skip entire modules based on evaluated conditional vars.

Purpose: This completes the v1.2 structured conditionals milestone by extending the four conditional fields (go_if_all_pass, go_if_any_pass, skip_if_all_pass, skip_if_any_pass) to module references. Previously, conditionals could only target individual resources or resource blocks. Now entire modules can be conditionally included/excluded at the role and client config level.

Output: ModuleRef type with YAML unmarshaler supporting both plain string (`- nginx`) and object form (`- name: nginx, go_if_all_pass: is_debian`), ShouldIncludeModule evaluator, updated loader and check-in pipeline with full test coverage.
</objective>
