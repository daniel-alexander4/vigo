**In server/config/types.go:**

1. Add a `StringOrSlice` type (`type StringOrSlice []string`) that implements `yaml.UnmarshalYAML`:
   - If the YAML node is a scalar string, set to `[]string{value}`
   - If the YAML node is a sequence, unmarshal as `[]string`
   - This handles both `go_if_all_pass: is_debian` and `go_if_all_pass: [is_debian, has_mem]`

2. Add four fields to `ResourceConfig` (BEFORE the `Attributes` inline field to ensure they are parsed by the struct tags and not captured by inline):
   ```go
   GoIfAllPass   StringOrSlice `yaml:"go_if_all_pass,omitempty"`
   GoIfAnyPass   StringOrSlice `yaml:"go_if_any_pass,omitempty"`
   SkipIfAllPass StringOrSlice `yaml:"skip_if_all_pass,omitempty"`
   SkipIfAnyPass StringOrSlice `yaml:"skip_if_any_pass,omitempty"`
   ```

**In server/config/conditionals.go (new file):**

Create `ShouldRunResource(res ResourceConfig, vars map[string]any) bool`:

1. Helper `varIsTrue(name string, vars map[string]any) bool` -- returns true only if `vars[name] == "true"` (string). Unknown var names or non-"true" values return false.

2. Evaluation logic (all constraints must hold):
   - If `GoIfAllPass` is non-empty: ALL listed var names must be true. If any is false -> return false.
   - If `GoIfAnyPass` is non-empty: at least ONE listed var name must be true. If none are true -> return false.
   - If `SkipIfAllPass` is non-empty: if ALL listed var names are true -> return false (skip). Otherwise continue.
   - If `SkipIfAnyPass` is non-empty: if ANY listed var name is true -> return false (skip). Otherwise continue.
   - If all checks pass (or no fields set) -> return true.

3. Evaluate go_if fields first (they gate execution), then skip_if fields (they veto execution). Order: GoIfAllPass, GoIfAnyPass, SkipIfAllPass, SkipIfAnyPass.

**Write tests first (RED), then implement (GREEN).**
