  <name>Task 2: sqlc queries for facts/snapshots, server ReportResult/ReportFacts handlers, CheckIn facts integration</name>
  <files>server/db/queries/facts.sql, server/db/queries/snapshots.sql, server/grpc/report.go, server/grpc/facts.go, server/grpc/checkin.go</files>
  <action>
    Create `server/db/queries/facts.sql` with sqlc queries:
    ```sql
    -- name: InsertClientFacts :one
    INSERT INTO client_facts (client_id, facts)
    VALUES ($1, $2)
    RETURNING id, client_id, facts, collected_at;

    -- name: GetLatestClientFacts :one
    SELECT id, client_id, facts, collected_at
    FROM client_facts
    WHERE client_id = $1
    ORDER BY collected_at DESC
    LIMIT 1;

    -- name: PruneClientFacts :exec
    DELETE FROM client_facts
    WHERE client_id = $1
    AND id NOT IN (
      SELECT id FROM client_facts
      WHERE client_id = $1
      ORDER BY collected_at DESC
      LIMIT 10
    );
    ```

    Create `server/db/queries/snapshots.sql` with sqlc queries:
    ```sql
    -- name: InsertFileSnapshot :one
    INSERT INTO file_snapshots (client_id, file_path, content_hash, content, run_id)
    VALUES ($1, $2, $3, $4, $5)
    RETURNING id, client_id, file_path, content_hash, content, created_at, run_id;

    -- name: ListFileSnapshots :many
    SELECT id, client_id, file_path, content_hash, content, created_at, run_id
    FROM file_snapshots
    WHERE client_id = $1 AND file_path = $2
    ORDER BY created_at DESC;
    ```

    Run `make proto` to regenerate if proto changes needed, then run sqlc generate:

    Create `server/grpc/report.go` implementing `AgentService.ReportResult`:
