Executor interface contract (defined by Plan 01 in agent/modules/executor.go):
```go
type ActionTaken string

const (
    ActionNone    ActionTaken = "none"
    ActionCreated ActionTaken = "created"
    ActionUpdated ActionTaken = "updated"
    ActionDeleted ActionTaken = "deleted"
    ActionSkipped ActionTaken = "skipped"
)

type ResourceResult struct {
    ModuleName   string
    ResourceType string
    ResourceName string
    Action       ActionTaken
    Changed      bool
    Error        error
    DurationMs   int32
}

type Executor interface {
    Execute(ctx context.Context, params map[string]string, dryRun bool) ResourceResult
}
```

    Create `agent/modules/pkgmgr/interface.go`:

    - `IsInstalled` uses the distro-specific query command
    - `Install` uses the distro-specific install command with non-interactive flags
    - `Remove` uses the distro-specific remove command
    - `Upgrade` uses the distro-specific upgrade command (or install with version)

      - dnf: `rpm -q` (query), `dnf install -y` (install), `dnf remove -y` (remove)

      - pacman: `pacman -Q` (query), `pacman -S --noconfirm` (install), `pacman -R --noconfirm` (remove)
      - brew: `brew list` (query), `brew install` (install), `brew uninstall` (remove)
      - zypper: `zypper se -i` (query), `zypper install -y` (install), `zypper remove -y` (remove)

    - Fields: `PkgMgr pkgmgr.PackageManager`
    - Params: `name`, `state` (present/absent), `version` (optional)
    - Execute: calls `PkgMgr.IsInstalled`, then Install/Remove/Upgrade based on state and version
    - Records ActionCreated (installed), ActionDeleted (removed), ActionUpdated (upgraded), ActionNone (already correct)

    Create `agent/modules/service.go` with `ServiceExecutor`:
    - Field `Runner CommandRunner` (for testable exec.Command calls)
    - Params: `name`, `state` (running/stopped/restarted/reloaded), `enabled` (true/false)
    - `isActive(ctx, name)`: runs `systemctl is-active --quiet name`, exit 0 = active
    - `isEnabled(ctx, name)`: runs `systemctl is-enabled --quiet name`, exit 0 = enabled
    - State logic: running=start if not active, stopped=stop if active, restarted=always restart, reloaded=always reload
    - Enabled logic: enable if enabled=true and not currently enabled, disable if enabled=false and currently enabled
    - Dry-run: check state, return planned action

    Create `agent/modules/user.go` with `UserExecutor`:
    - Field `Runner CommandRunner`, `PasswdPath string` (default `/etc/passwd`, overridable for tests)

    - Checks `os/user.Lookup(name)` for existence
    - For attribute comparison: parses passwd file line for uid, shell, home
    - Creates via `useradd`, modifies via `usermod`, removes via `userdel`
    - Dry-run: check state, return planned action

    Create `agent/modules/exec.go` with `ExecExecutor`:
    - Field `Runner CommandRunner`
    - Params: `command`, `creates` (file path), `onlyif` (command), `unless` (command), `cwd`, `user`
    - Guard order: (1) if `creates` path exists, skip; (2) if `onlyif` command fails, skip; (3) if `unless` command succeeds, skip
    - Execute: runs command via `exec.CommandContext`, with optional `cwd` and `user`
    - Dry-run: evaluate guards only, return whether command would run

    All executor tests use interface-based mocking (mock CommandRunner for service/user/exec, mock PackageManager for package). No root or real systemd required.
