  <files>agent/checkin/client.go, agent/checkin/loop.go, agent/checkin/backoff.go, agent/checkin/loop_test.go</files>
  <action>
    Promote cenkalti/backoff from indirect to direct dependency:
    ```
    go get github.com/cenkalti/backoff/v4@latest
    ```

    Create `agent/checkin/client.go` with `Client` struct:
    - Fields: `conn *grpc.ClientConn`, `agent pb.IsgovAgentClient`, `clientID string`, `privateKey ed25519.PrivateKey`
    - `NewClient(serverAddr, caFile, clientCertFile, clientKeyFile, clientID string, privateKey ed25519.PrivateKey) (*Client, error)`:
      - Loads TLS credentials: CA cert for server verification, client cert/key for mTLS
      - Creates gRPC dial with `grpc.WithTransportCredentials`
      - For dev mode: if clientCertFile is empty, connect with just CA verification (no client cert) -- the server's signature interceptor provides real auth via ED25519
    - `CheckIn(ctx context.Context, stateFingerprint string) (*pb.CheckInResponse, error)`:
      - Signs payload (state_fingerprint + timestamp as Unix epoch string) with ED25519 private key
      - Calls `agent.CheckIn` with signed request
    - `ReportResult(ctx context.Context, runID string, results []*pb.ModuleResult) error`:
      - Signs payload (run_id + timestamp) with ED25519 private key
      - Calls `agent.ReportResult` with signed request
    - `ReportFacts(ctx context.Context, factsJSON []byte) error`:
      - Signs payload (facts_json + timestamp)
      - Calls `agent.ReportFacts` with signed request
    - `Close() error`: closes gRPC connection

    Create `agent/checkin/backoff.go`:
    - `NewBackoff() backoff.BackOff`: returns `backoff.NewExponentialBackOff()` configured with:
      - InitialInterval: 5s, MaxInterval: 5m, MaxElapsedTime: 0 (never stop retrying)
      - Multiplier: 2.0
    - Wrap the cenkalti/backoff library for clean import

    Create `agent/checkin/loop.go`:
    - `jitteredDuration(base time.Duration, jitterPct int) time.Duration`:
      - Uses `math/rand/v2` for non-crypto randomness
      - Returns `base + time.Duration((rand.Float64()*2 - 1) * float64(base) * float64(jitterPct) / 100.0)`

    - `RunOnce(ctx context.Context, client *Client, executors map[string]modules.Executor, facts map[string]any, dryRun bool, module string) ([]modules.ResourceResult, error)`:
      - Calls `client.CheckIn` with state fingerprint (compute from facts hash)
      - Creates `runner.Runner` with executors, facts, dryRun, module
      - Calls `runner.Run` with CheckIn response modules
      - If not dry-run: calls `client.ReportResult` with results
      - Returns results

    - `Loop(ctx context.Context, client *Client, executors map[string]modules.Executor, snapshotMgr *snapshots.Manager) error`:
      - On each iteration:
        1. Collect facts via `facts.CollectAll(ctx, facts.DefaultCollectors())`
        2. Report facts via `client.ReportFacts`
        3. Call `RunOnce` with collected facts
        4. On success: reset backoff, sleep `jitteredDuration(baseInterval, jitterPct)` -- read from CheckIn response
        5. On error (server unavailable): use exponential backoff, log warning, never crash
        6. Respect ctx cancellation for graceful shutdown
      - Loops until ctx is cancelled (SIGINT/SIGTERM)

    Tests:
    - `jitteredDuration` produces values within [base - jitter, base + jitter] range
    - `jitteredDuration` with 0 jitter returns exact base
    - Loop backoff on server error does not crash (use mock client)
    - RunOnce dry-run does not call ReportResult
