  <name>Task 1: Executor interface, file executor with SHA256 + atomic write, and snapshot manager</name>
  <files>agent/modules/executor.go, agent/modules/file.go, agent/modules/executor_test.go, agent/modules/file_test.go, agent/snapshots/manager.go, agent/snapshots/manager_test.go</files>
  <behavior>
    - Executor interface: Execute(ctx, params map[string]string, dryRun bool) returns ResourceResult
    - ActionTaken type: constants for none, created, updated, deleted, skipped
    - ResourceResult: ModuleName, ResourceType, ResourceName, Action, Changed, Error, DurationMs fields
    - FileExecutor SHA256 check: existing file with matching hash + mode/owner = ActionNone, Changed=false
    - FileExecutor new file: creates file = ActionCreated, Changed=true
    - FileExecutor changed content: updates file = ActionUpdated, Changed=true
    - FileExecutor dry-run: returns planned action without writing
    - FileExecutor atomic write: temp file created in filepath.Dir(target), renamed after write
    - FileExecutor sets mode via os.Chmod before rename
    - FileExecutor calls snapshot manager Save before overwriting existing files
    - Snapshot Save: copies existing file to /var/lib/isogov/snapshots/<sha256-of-path>.<run-uuid>.bak
    - Snapshot Prune: keeps only last 5 snapshots per file path, deletes oldest
    - Snapshot Restore: copies snapshot back to original path
    - Snapshot dir created with MkdirAll 0700 on first Save
  </behavior>
  <action>
    Create `agent/modules/executor.go` with:
    - `ActionTaken` string type with constants: `ActionNone`, `ActionCreated`, `ActionUpdated`, `ActionDeleted`, `ActionSkipped`
    - `ResourceResult` struct with fields: `ModuleName string`, `ResourceType string`, `ResourceName string`, `Action ActionTaken`, `Changed bool`, `Error error`, `DurationMs int32`
    - `Executor` interface with `Execute(ctx context.Context, params map[string]string, dryRun bool) ResourceResult`

    Create `agent/modules/file.go` with `FileExecutor` struct:
    - Field `SnapshotMgr *snapshots.Manager` (optional, nil = no snapshots)
    - Field `RunID string` (for snapshot naming)
    - `Execute` checks SHA256 hash of existing file via `crypto/sha256` + `io.Copy`
    - Compares desired content hash against current; if match, checks mode/owner
    - If all match: returns `ActionNone, Changed=false`
    - If dry-run: returns planned action without writing
    - Before overwrite: calls `SnapshotMgr.Save(path)` if manager is non-nil
    - Atomic write: `os.CreateTemp(filepath.Dir(path), ".isogov-*")`, write content, `os.Chmod`, `os.Rename`
    - Handles absent directory with `os.MkdirAll` on the parent dir
    - Params used: `path`, `content`, `mode` (default "0644"), `owner`, `group`, `state` (present/absent)
    - For state=absent: removes file if exists, returns ActionDeleted
    - PITFALL: temp file MUST be in same directory as target (not $TMPDIR) to avoid EXDEV on rename

    Create `agent/snapshots/manager.go` with `Manager` struct:
    - Field `BaseDir string` (default `/var/lib/isogov/snapshots`)
    - Field `MaxPerPath int` (default 5)
    - `Save(filePath, runID string) error`: copies file to `<baseDir>/<sha256-of-path>.<runID>.bak`, prunes old
    - `Restore(filePath, snapshotPath string) error`: copies snapshot back
    - `Prune(filePath string) error`: lists snapshots for path, deletes oldest beyond MaxPerPath
    - Uses sha256 hex of the file path as the prefix for grouping snapshots
    - `os.MkdirAll(baseDir, 0700)` on first Save

    Tests use `os.MkdirTemp` for real filesystem operations. Mock snapshot manager for file executor tests where snapshot behavior is not the focus.
  </action>

  </verify>
  <done>FileExecutor passes SHA256 idempotency tests, atomic write tests, dry-run tests, snapshot integration tests. Snapshot manager prunes to 5 per path. All tests green with -race.</done>
</task>

  </behavior>
