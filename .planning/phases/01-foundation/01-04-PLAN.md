  <name>Task 1: ED25519 keypair generation, PEM storage, and request signing</name>
  <files>agent/auth/keypair.go, agent/auth/signer.go, agent/auth/keypair_test.go, agent/auth/signer_test.go</files>
  <behavior>
    - TestGenerateKeypair: Generates valid ED25519 keypair, returns pub+priv
    - TestSaveAndLoadKeypair: Save to temp dir, load back, keys match
    - TestLoadKeypairFileNotExist: Returns specific error when key file doesn't exist (triggers generation)
    - TestPublicKeyPEM: Exports public key in PKIX PEM format parseable by x509.ParsePKIXPublicKey
    - TestPrivateKeyPEM: Private key stored in PKCS8 PEM format parseable by x509.ParsePKCS8PrivateKey
    - TestSignPayload: Sign(payload, privateKey) produces non-empty signature bytes
    - TestVerifyPayload: Verify(payload, signature, publicKey) returns true for valid signature
    - TestVerifyPayloadTampered: Verify with modified payload returns false
    - TestVerifyPayloadWrongKey: Verify with different public key returns false
    - TestSignatureIncludesTimestamp: SignRequest(payload, timestamp, key) includes timestamp in signed data to prevent replay
  </behavior>
  <action>
1. Create `agent/auth/keypair.go`:
   - `GenerateKeypair() (ed25519.PublicKey, ed25519.PrivateKey, error)` -- uses `crypto/ed25519.GenerateKey(nil)` (AGNT-11)
   - `SaveKeypair(dir string, priv ed25519.PrivateKey) error` -- marshals via `x509.MarshalPKCS8PrivateKey`, PEM encodes with block type "PRIVATE KEY", writes to `{dir}/agent.key` with 0600 permissions (pitfall 8)
   - `LoadKeypair(dir string) (ed25519.PublicKey, ed25519.PrivateKey, error)` -- reads PEM, `x509.ParsePKCS8PrivateKey`, extracts public key
   - `PublicKeyPEM(pub ed25519.PublicKey) (string, error)` -- marshals via `x509.MarshalPKIXPublicKey`, PEM encodes with block type "PUBLIC KEY"
   - `LoadOrGenerate(dir string) (ed25519.PublicKey, ed25519.PrivateKey, error)` -- tries Load, if not exist then Generate+Save

2. Create `agent/auth/signer.go`:
   - `SignPayload(payload []byte, timestamp string, key ed25519.PrivateKey) []byte` -- signs `payload + []byte(timestamp)` (SEC-02)
   - `VerifyPayload(payload []byte, timestamp string, sig []byte, pub ed25519.PublicKey) bool` -- verifies signature (SEC-03 server-side use)
   - Timestamp inclusion prevents replay attacks (5-min window enforced server-side in Plan 05)

3. Write tests first, then implement (TDD)
  </action>

  </verify>
