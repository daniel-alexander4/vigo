  <name>Task 1: Initialize Go module, proto definitions, and buf codegen</name>
  <files>go.mod, go.sum, proto/isogov.proto, buf.yaml, buf.gen.yaml, gen/proto/isogov/, .gitignore</files>
  <action>
1. Initialize Go module: `go mod init github.com/isogov/isogov`

2. Create `proto/isogov.proto` with TWO services in one file (per locked decision -- single proto file):
   - `IsgovAgent` service (gRPC-only, agent traffic on 9090):
     - `Register(RegisterRequest) returns (RegisterResponse)` -- agent enrollment
     - `CheckIn(CheckInRequest) returns (CheckInResponse)` -- agent pull
     - `ReportResult(ReportResultRequest) returns (ReportResultResponse)` -- run results
     - `ReportFacts(ReportFactsRequest) returns (ReportFactsResponse)` -- fact submission
   - `IsgovAdmin` service (gRPC + grpc-gateway REST annotations, admin traffic on 8080):
     - `AddApprovedPattern`, `ListApprovedPatterns`, `RevokeApprovedPattern`
     - `ListClients`, `GetClient`, `RevokeClient`
     - `ForcePush`, `DryRun`
     - `ListRuns`, `GetRun`
     - `GenerateToken`
   - All message types from the handoff spec (RegisterRequest with hostname/ip/pubkey_pem/token, CheckInRequest with client_id/state_fingerprint/signature/timestamp, etc.)
   - Use `google.protobuf.Timestamp` for time fields, `string` for UUIDs
   - Add `google.api.http` annotations on all IsgovAdmin RPCs

3. Create `buf.yaml` with v2 config:
   - module path: `proto`, name: `buf.build/isogov/isogov`
   - deps: `buf.build/googleapis/googleapis`, `buf.build/grpc-ecosystem/grpc-gateway`
   - lint: DEFAULT, breaking: FILE

4. Create `buf.gen.yaml` with v2 config:
   - protocolbuffers/go plugin -> gen/proto, paths=source_relative
   - grpc/go plugin -> gen/proto, paths=source_relative
   - grpc-ecosystem/gateway plugin -> gen/proto, paths=source_relative, generate_unbound_methods=true
   - grpc-ecosystem/openapiv2 plugin -> gen/openapi

5. Run `buf dep update` then `buf generate` to produce Go stubs

6. Install all Go dependencies per RESEARCH.md standard stack (grpc, pgx, golang-migrate, fsnotify, cobra, yaml.v3, bcrypt, godotenv, uuid, testcontainers-go)

7. Create `.gitignore` with: certs/, .env, bin/, gen/ (or not -- generated code can be committed for CI), vendor/, *.exe

8. Verify: `go build ./...` compiles cleanly

<task type="auto">
  <name>Task 2: Database migrations, sqlc queries, and infrastructure files</name>
  <files>migrations/*.sql, server/db/queries/*.sql, sqlc.yaml, Makefile, docker-compose.yml, Dockerfile.server, Dockerfile.agent, .env.example</files>
  <action>
1. Create ALL 11 migration pairs (up/down) per DB-02 with sequential numbering. Follow the handoff spec schema exactly. ALL tables use UUID PKs (DB-03) via `gen_random_uuid()`:
   - 000001: approved_patterns (id UUID PK, pattern TEXT NOT NULL, token_hash TEXT NOT NULL, created_at TIMESTAMPTZ, used_at TIMESTAMPTZ, used_by UUID REFERENCES clients)
   - 000002: clients (id UUID PK, hostname TEXT NOT NULL, ip_address TEXT, pubkey_pem TEXT NOT NULL, enrolled_at TIMESTAMPTZ, last_seen TIMESTAMPTZ, revoked BOOLEAN DEFAULT false, revoked_at TIMESTAMPTZ)
   - 000003: runs (id UUID PK, client_id UUID REFERENCES clients, started_at TIMESTAMPTZ, finished_at TIMESTAMPTZ, status TEXT, module_count INT, changed_count INT, failed_count INT, skipped_count INT)
   - 000004: run_results (id UUID PK, run_id UUID REFERENCES runs, module_name TEXT, resource_type TEXT, resource_name TEXT, action_taken TEXT, changed BOOLEAN, error_message TEXT, duration_ms INT)
   - 000005: client_facts (id UUID PK, client_id UUID REFERENCES clients, facts JSONB, collected_at TIMESTAMPTZ)
   - 000006: plans (id UUID PK, client_id UUID REFERENCES clients, created_at TIMESTAMPTZ, modules JSONB)
   - 000007: plan_results (id UUID PK, plan_id UUID REFERENCES plans, module_name TEXT, resource_type TEXT, resource_name TEXT, planned_action TEXT)
   - 000008: file_snapshots (id UUID PK, client_id UUID REFERENCES clients, file_path TEXT, content_hash TEXT, content BYTEA, created_at TIMESTAMPTZ, run_id UUID REFERENCES runs)
   - 000009: secret_rotation_events (id UUID PK, secret_path TEXT, old_version TEXT, new_version TEXT, rotated_at TIMESTAMPTZ, affected_clients INT)
   - 000010: package_audit (id UUID PK, client_id UUID REFERENCES clients, package_name TEXT, installed_version TEXT, desired_version TEXT, detected_at TIMESTAMPTZ)
   - 000011: webhooks (id UUID PK, url TEXT NOT NULL, secret TEXT, events TEXT[] NOT NULL, created_at TIMESTAMPTZ, active BOOLEAN DEFAULT true)
   - Down migrations: DROP TABLE IF EXISTS for each
   - Add indexes: clients(hostname), runs(client_id), client_facts(client_id, collected_at), run_results(run_id)

2. Create `sqlc.yaml` at project root per RESEARCH.md example -- engine: postgresql, queries: server/db/queries/, schema: migrations/, gen go package "db" out "server/db", sql_package pgx/v5, overrides for uuid and timestamptz

3. Create sqlc query files in `server/db/queries/`:

   - `runs.sql`: CreateRun, GetRunByID, ListRunsByClient, CreateRunResult, ListRunResults

4. Run `sqlc generate` to produce server/db/*.go

5. Create `Makefile` with targets: build, proto, certs, test, lint, seed, migrate -- per RESEARCH.md Makefile skeleton. The `certs` target MUST include SANs for localhost, isogov, server, 127.0.0.1 (pitfall 1).
