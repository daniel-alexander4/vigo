  <name>Task 1: mTLS gRPC server, Register/CheckIn handlers, and signature interceptor</name>
  <files>server/main.go, server/grpc/server.go, server/grpc/register.go, server/grpc/checkin.go, server/grpc/interceptor.go, server/grpc/server_test.go</files>
  <action>
1. Create `server/grpc/server.go`:
   - `NewServer(cfg ServerConfig) (*grpc.Server, error)` -- configures mTLS:
     - Load server cert+key from paths in config
     - Load CA cert for client verification
     - `tls.Config` with `ClientAuth: tls.RequireAndVerifyClientCert`, `MinVersion: tls.VersionTLS13` (SEC-01)
     - For SEC-05: cert paths come from config (volume-mountable for production)
     - Register IsgovAgent and IsgovAdmin services
   - `ServerConfig` struct: CertFile, KeyFile, CAFile, GRPCPort, Registry, ConfigStore, Queries

2. Create `server/grpc/interceptor.go`:
   - `SignatureVerifyInterceptor` -- unary server interceptor (SEC-03):
     - Skip verification for Register RPC (agent doesn't have UUID yet)
     - Extract client_id, signature, timestamp from request metadata or fields
     - Look up client pubkey from DB by client_id
     - Check timestamp within 5-minute window (replay prevention)
     - Call `auth.VerifyPayload(payload, timestamp, signature, pubkey)`
     - Reject with codes.Unauthenticated if invalid

3. Create `server/grpc/register.go`:
   - `Register(ctx, req *pb.RegisterRequest) (*pb.RegisterResponse, error)`
   - Delegates to `registry.Register(ctx, req.Hostname, req.IpAddress, req.PubkeyPem, req.Token)`
   - Returns client UUID on success

4. Create `server/grpc/checkin.go`:
   - `CheckIn(ctx, req *pb.CheckInRequest) (*pb.CheckInResponse, error)`
   - Validates client not revoked via `registry.ValidateClient()`
   - Looks up client config via `configStore.Get(hostname)` -- falls back to classifier
   - If no config: return empty module list (CONF-08)
   - Renders templates at check-in time with facts and vars (locked decision)
   - Returns compiled module list

5. Create `server/main.go`:
   - Load server.yaml config, resolve secrets via StaticProvider
   - Connect to PostgreSQL via pgxpool (DSN from resolved secret)
   - Run migrations via golang-migrate
   - Initialize sqlc Queries, Registry, ConfigStore
   - Start gRPC server on :9090
   - Start REST gateway on :8080 (next task)
   - Graceful shutdown on SIGINT/SIGTERM

6. Write integration tests in `server/grpc/server_test.go`:
   - TestMTLSRequired: plaintext connection rejected
   - TestRegisterFlow: full registration via gRPC
   - TestCheckInRevoked: revoked client gets error
   - Use testcontainers-go for real PostgreSQL
