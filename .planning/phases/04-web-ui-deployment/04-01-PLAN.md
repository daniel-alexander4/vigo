   - `NewHandler(queries *db.Queries, configStore *config.ConfigStore, baseInterval time.Duration, serverAddr, caFile, agentDir, version string) (*Handler, error)` — creates renderer, returns handler
   - `RegisterRoutes(mux *http.ServeMux)` — registers all UI routes on the mux:
     - `GET /` -> Dashboard (exact match)
     - `GET /clients` -> Clients
     - `GET /clients/{id}` -> ClientDetail (Go 1.22+ path pattern)
     - `GET /runs` -> Runs
     - `GET /runs/{id}` -> RunDetail
     - `GET /config/{hostname}` -> Config
     - `GET /plans/{id}` -> Plans
     - `GET /compliance` -> Compliance
     - `GET /ui/fragments/dashboard-stats` -> DashboardStats (HTMX fragment)
     - `GET /ui/fragments/clients-table` -> ClientsTable (HTMX fragment)
     - Static file serving: `GET /static/` -> http.FileServerFS from embedded static/ subdir
   - `Dashboard(w, r)` handler:
     - Fetch all clients via `queries.ListClients(ctx)`
     - Compute total, active in last hour (LastSeen within 1 hour), recent failures (from last 10 runs with status "failure"), drift rate (from compliance computation)
     - For each non-revoked client: fetch latest run, compute compliance status
     - Fetch last 10 runs via `queries.ListAllRuns(ctx, 10)` for recent activity table
     - Render "dashboard" page with stats + recent activity
   - `DashboardStats(w, r)` fragment handler:
     - Same data fetch as Dashboard stat cards
     - Render only the stat-cards partial (HTML fragment for HTMX swap)
   - `Compliance(w, r)` handler:
     - Fetch all clients, compute compliance status for each
     - Calculate summary: total, compliant count, drifted, failing, stale, unknown
     - Calculate compliance percentage: (compliant / total) * 100
     - Fetch 30-day compliance history via `queries.ListComplianceHistory(ctx, 30)`
     - Extract daily compliant percentages for sparkline data points
     - Build non-compliant clients table (clients where status != "compliant")
     - Render "compliance" page with gauge, sparkline, breakdown, table
