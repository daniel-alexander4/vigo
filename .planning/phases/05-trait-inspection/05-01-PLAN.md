Create `agent/traits.go` with:

1. A `traitsCmd` cobra.Command registered under rootCmd:
   - Use: `traits [collector...] or traits <dot.path>`
   - Args: cobra.ArbitraryArgs
   - No PersistentPreRunE override needed -- the root PersistentPreRunE calls setupLogger() which is fine, BUT: suppress slog for traits by setting log level to error-only at the start of RunE (override the configured level with `slog.SetDefault(slog.New(slog.NewTextHandler(os.Stderr, &slog.HandlerOptions{Level: slog.LevelError})))`)

2. RunE logic:
   - Get all default collectors via `facts.DefaultCollectors()`
   - If args provided, check if first arg contains a dot (`.`) -- if so, it is a dot-path query:
     a. Collect ALL traits (no filtering by collector)
     b. Call `traverseDotPath(traitsMap, dotPath)` to extract the value
     c. If not found, print error to stderr and return exit 1: `trait path '<path>' not found`
     d. Call `formatValue(value)` to print: raw string for scalars, pretty JSON for maps/slices
   - If args provided and NO dot, treat as collector name filters:
     a. Filter collectors to only those whose Name() matches an arg
     b. If any arg matches no collector, print error to stderr and exit 1
     c. Collect traits using filtered collectors
     d. Pretty-print the resulting map as JSON (2-space indent) to stdout
   - If no args: collect all traits, pretty-print entire map as JSON to stdout
   - Use `json.MarshalIndent(traits, "", "  ")` for pretty printing
   - Print to stdout via `fmt.Println(string(jsonBytes))`
   - Errors to stderr via `fmt.Fprintf(os.Stderr, ...)`

3. Helper functions (unexported):
   - `traverseDotPath(data map[string]any, path string) (any, bool)` -- splits on `.`, walks the map
   - `filterCollectors(all []facts.Collector, names []string) ([]facts.Collector, error)` -- returns matching collectors or error for unknown names
   - `formatValue(v any) string` -- string/number/bool returns `fmt.Sprint(v)`, map/slice returns pretty JSON

4. In `init()`: `rootCmd.AddCommand(traitsCmd)`

Create `agent/traits_test.go` with tests for traverseDotPath, filterCollectors, and formatValue.
