<objective>
Add custom trait manifest generation and download RPC to the server.

Purpose: The server must scan a `traits/` directory for executables, compute their SHA256 checksums, embed the manifest in every CheckInResponse, and serve individual executables via a new DownloadCustomTrait gRPC RPC. This is the server-side foundation that agents will consume to sync and execute custom traits.

Output: Updated proto with CustomTraitEntry message + DownloadCustomTrait RPC, regenerated Go stubs, server/traits/ package with directory scanner, updated CheckIn handler embedding manifest, new DownloadCustomTrait handler.
