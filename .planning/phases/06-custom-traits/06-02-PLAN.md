<objective>
Implement agent-side custom trait sync, execution, and merging into the traits map.

Purpose: Agents must compare the manifest from CheckIn against locally cached executables, download new/changed ones via gRPC, execute each with a 10-second timeout, parse JSON stdout, and merge results under `custom.<name>` in the facts map. Failures must be non-fatal -- a broken trait script must never block convergence.

Output: agent/traits/ package with sync + execute logic, DownloadCustomTrait client method, loop integration with custom traits running before built-in fact collection.
</objective>

    - SyncAndRun with manifest containing 2 new traits: downloads both, executes both, returns merged map with custom.trait1 and custom.trait2 keys
    - SyncAndRun with manifest matching local cache (same checksums): no downloads, still executes and returns results
    - SyncAndRun with one changed checksum: downloads only the changed one, executes all
    - Execute trait outputting valid JSON `{"version":"1.2.3"}`: merged as custom.app-version.version = "1.2.3"
    - Execute trait outputting nested JSON: nested structure preserved under custom.<name>
    - Execute trait that exits non-zero: logs warning, key absent from result, other traits unaffected
    - Execute trait that outputs invalid JSON: logs warning, key absent from result
    - Execute trait that exceeds 10s timeout: killed, logs warning, key absent from result
    - SyncAndRun with empty manifest: returns empty map (no custom.* keys), no errors
    - Stale cached executables not in manifest are cleaned up (deleted from cache dir)
  </behavior>
  <action>
    1. Create agent/traits/executor.go:
       - `type Downloader interface { DownloadCustomTrait(ctx context.Context, name string) ([]byte, error) }` -- abstracts gRPC download for testability
       - `type Executor struct { cacheDir string; downloader Downloader; timeout time.Duration }`
       - `func NewExecutor(cacheDir string, downloader Downloader, timeout time.Duration) *Executor`
       - `func (e *Executor) SyncAndRun(ctx context.Context, manifest []*pb.CustomTraitEntry) (map[string]any, error)`:
         a. Ensure cacheDir exists (os.MkdirAll)
         b. Build map of local cached files with their SHA256 checksums (read dir, compute hash)
         c. For each manifest entry: if local checksum differs or file missing, call downloader.DownloadCustomTrait, write to cacheDir/<name> with 0755 permissions
         d. Clean up stale files: any file in cacheDir not in manifest gets deleted
         e. Execute each manifest entry's cached executable: `exec.CommandContext` with timeout context, capture stdout, parse JSON
         f. For each successful execution, set result["custom.<name>"] = parsed JSON map. Use a nested structure: result is `map[string]any` where key "custom" maps to another `map[string]any` with trait names as keys
         g. Failed/timed-out executables: log warning with slog, skip that trait, continue
         h. Return the merged map (caller merges into factsMap)

       - Helper: `func localChecksums(dir string) (map[string]string, error)` -- reads dir, computes SHA256 for each file
       - Helper: `func (e *Executor) runOne(ctx context.Context, name, path string) (map[string]any, error)` -- executes one trait with timeout, parses JSON stdout
       - Timeout: use `context.WithTimeout(ctx, e.timeout)` per executable. Default 10s per CONTEXT.md decisions
       - JSON parsing: `json.Unmarshal(stdout, &map[string]any{})` -- if unmarshal fails, return error (caller logs and skips)
