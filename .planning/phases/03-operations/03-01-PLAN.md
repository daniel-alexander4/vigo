**New sqlc query files:**

`server/db/queries/webhooks.sql`:
- `CreateWebhook :one` -- INSERT url, secret, events RETURNING *
- `ListActiveWebhooks :many` -- SELECT * WHERE active = true ORDER BY created_at DESC
- `ListActiveWebhooksByEvent :many` -- SELECT * WHERE active = true AND $1 = ANY(events)
- `GetWebhookByID :one` -- SELECT * WHERE id = $1
- `DeleteWebhook :exec` -- DELETE WHERE id = $1
- `DeactivateWebhook :exec` -- UPDATE SET active = false WHERE id = $1

`server/db/queries/package_audit.sql`:
- `CreatePackageAudit :one` -- INSERT client_id, package_name, installed_version, desired_version RETURNING *
- `ListPackageAuditByClient :many` -- SELECT * WHERE client_id = $1 ORDER BY detected_at DESC
- `ListPackageDrift :many` -- SELECT * WHERE installed_version IS DISTINCT FROM desired_version ORDER BY detected_at DESC
- `ListAllPackageAudit :many` -- SELECT * ORDER BY detected_at DESC LIMIT $1

`server/db/queries/secret_rotation_events.sql`:
- `CreateSecretRotationEvent :one` -- INSERT secret_path, old_version, new_version, affected_clients RETURNING *
- `ListSecretRotationEvents :many` -- SELECT * ORDER BY rotated_at DESC LIMIT $1

`server/db/queries/plans.sql`:
- `CreatePlan :one` -- INSERT client_id, modules RETURNING *
- `GetPlanByID :one` -- SELECT * WHERE id = $1
- `ListPlansByClient :many` -- SELECT * WHERE client_id = $1 ORDER BY created_at DESC LIMIT $2
- `CreatePlanResult :one` -- INSERT plan_id, module_name, resource_type, resource_name, planned_action RETURNING *
- `ListPlanResults :many` -- SELECT * WHERE plan_id = $1 ORDER BY id ASC
