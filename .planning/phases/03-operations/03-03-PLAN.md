**Create `cli/client.go`** -- shared HTTP client for all gvctl commands:

```go
type apiClient struct {
    baseURL    string
    httpClient *http.Client
}

func newAPIClient() *apiClient  // uses global serverURL from main.go
func (c *apiClient) get(path string, result any) error     // GET + JSON decode
func (c *apiClient) post(path string, body, result any) error  // POST JSON + decode
func (c *apiClient) delete(path string, result any) error  // DELETE + decode
```

Error handling: On non-2xx responses, read body and return `fmt.Errorf("server returned %d: %s", statusCode, body)`. Timeout: 30 seconds.

**Create `cli/approved.go`** -- replace inline stubs with real implementations:
- `approved add <pattern> --token <token>`: POST /api/v1/approved with {pattern, token}. Print created pattern ID.
- `approved list`: GET /api/v1/approved. Print table: ID | Pattern | Created | Used.
- `approved revoke <id>`: DELETE /api/v1/approved/{id}. Print confirmation.

**Create `cli/clients.go`**:
- `clients list`: GET /api/v1/clients. Print table: Hostname | IP | Enrolled | Last Seen | Status.
- `clients show <id>`: GET /api/v1/clients/{id}. Print full detail. Also GET /api/v1/clients/{id}/compliance for status.
- `clients revoke <id>`: POST /api/v1/clients/{id}/revoke. Print confirmation.

**Create `cli/push.go`**:
- `push <hostname-or-uuid>`: POST /api/v1/push with {client_id: arg}. Print clients notified count.
- `push --all`: POST /api/v1/push with empty client_id. Add `--all` bool flag.

**Create `cli/runs.go`**:
- `runs list [--client <id>] [--limit 20]`: GET /api/v1/runs?client_id=X&limit=N. Print table: ID | Client | Started | Status | Changed | Failed.
- `runs show <id>`: GET /api/v1/runs/{id}. Print run header + per-module results table.

**Create `cli/tokens.go`**:
- `tokens generate`: POST /api/v1/tokens. Print generated token. Also print bootstrap curl command: `curl -fsSL http://<server>/bootstrap | ISOGOV_TOKEN=<token> bash`

**Update `cli/main.go`**:
- Remove all inline cobra.Command definitions for existing subcommands.
- Import and add commands from separate files.
- Keep `serverURL` global and `--server` flag.

**Create `cli/client_test.go`**:
- Test apiClient.get/post/delete against httptest.Server returning canned JSON responses.
- Test error handling for non-2xx responses.

Output formatting: Use `text/tabwriter` for aligned table output. Format timestamps as RFC3339 short (2006-01-02 15:04).

**Create `cli/preview.go`** (CLI-07):

- `preview --all`: List all clients, call dry-run for each, print aggregated results.
- `preview --env <env>`: Filter clients by environment, call dry-run for each.

**Create `cli/rollback.go`** (CLI-08):
