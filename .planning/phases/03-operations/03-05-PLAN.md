```go
package secrets

type IsopassProvider struct {
    baseURL     string
    bearerToken string
    token       string       // short-lived token from exchange
    tokenExpiry time.Time
    httpClient  *http.Client
    mu          sync.Mutex
}

func NewIsopassProvider(baseURL, bearerToken string) (*IsopassProvider, error)
func (p *IsopassProvider) Get(ctx context.Context, key string) (string, error)
func (p *IsopassProvider) GetBytes(ctx context.Context, key string) ([]byte, error)
func (p *IsopassProvider) GetVersion(ctx context.Context, key string) (int, error)
func (p *IsopassProvider) Close() error

// Internal methods:
func (p *IsopassProvider) ensureToken(ctx context.Context) error
func (p *IsopassProvider) exchangeToken(ctx context.Context) error
func (p *IsopassProvider) renewToken(ctx context.Context) error
func (p *IsopassProvider) search(ctx context.Context, query string) ([]searchResult, error)
func (p *IsopassProvider) getVersions(ctx context.Context, secretID string) ([]versionInfo, error)
```

**Authentication flow** (from research):
1. `exchangeToken`: POST /api/auth/token with Authorization: Bearer {bearerToken} -> receive short-lived token + expiry
2. `ensureToken`: Check if token is nil or expires within 60s -> exchangeToken() if needed
3. `renewToken`: POST /api/auth/token/renew with Authorization: Bearer {token} -> new token

**Get flow:**
1. Call ensureToken()
2. POST /api/sa/search with Authorization: Bearer {token}, body: {query: key}
3. Response contains array of secrets with Name, Value, ID fields
4. Find matching secret by name == key
5. Return Value
6. If no match, return error "secret %q not found in isopass"

**GetBytes flow:**
Same as Get but return []byte(value).

**GetVersion flow:**
1. First search to get secret ID
2. GET /api/secrets/{id}/versions with auth header
3. Return len(versions) as version number (or max version ID)

**Error handling:**
- HTTP errors: wrap with context "isopass request failed"
- 401/403: return "isopass authentication failed -- check bearer token"
- Connection refused: return "isopass unreachable at %s -- is isopass running?"
- Timeout: 10s per request

**Create `server/watcher/watcher.go`:**

```go
package watcher

type Watcher struct {
    provider     *secrets.IsopassProvider  // needs GetVersion
    queries      *db.Queries
    configStore  *config.ConfigStore
    dispatcher   *webhook.Dispatcher       // for secret.rotated events
    pollInterval time.Duration
    versions     map[string]int            // path -> last known version
    mu           sync.Mutex
}

func NewWatcher(provider *secrets.IsopassProvider, queries *db.Queries,
    configStore *config.ConfigStore, dispatcher *webhook.Dispatcher,
    pollInterval time.Duration, watchPaths []string) *Watcher

func (w *Watcher) Run(ctx context.Context) error  // blocking poll loop
func (w *Watcher) checkRotations(ctx context.Context)
```

**Run flow:**
1. Initialize versions map by calling GetVersion for each watched path
2. Start ticker at pollInterval
3. On each tick, call checkRotations()
4. On context cancellation, return

**checkRotations flow:**
For each watched path:
1. Call provider.GetVersion(ctx, path)
2. If error, log and continue (don't crash the watcher)
3. If currentVersion > lastVersion:
   a. Log rotation event
   b. Update versions map
   c. Find affected clients: call configStore.ClientsReferencingSecret(path)
   d. For each affected client, call queries.SetForcePush(ctx, clientID)
   e. Record audit: queries.CreateSecretRotationEvent(ctx, params)
   f. Dispatch webhook: dispatcher.Dispatch(ctx, "secret.rotated", payload)
