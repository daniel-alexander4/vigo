**Create `server/webhook/dispatcher.go`:**

```go
package webhook

type Dispatcher struct {
    queries    *db.Queries
    httpClient *http.Client
    maxRetries int
}

func NewDispatcher(queries *db.Queries) *Dispatcher
func (d *Dispatcher) Dispatch(ctx context.Context, event string, payload any)
func (d *Dispatcher) deliver(wh db.Webhook, event string, body []byte)
func sign(secret string, payload []byte) string  // HMAC-SHA256 hex
```

`Dispatch` flow:
1. Query `ListActiveWebhooksByEvent(ctx, event)` to get matching webhooks
2. Marshal payload to JSON
3. For each webhook, launch goroutine calling `deliver()`
4. Never block the caller -- fire and forget

`deliver` flow:
1. Create POST request with body
2. Set headers: Content-Type: application/json, X-Isogov-Signature: sha256={sign(wh.Secret, body)}, X-Isogov-Event: {event}
3. Send request
4. If error or status >= 300, retry up to maxRetries with linear backoff (attempt * 5s)
5. Log success/failure at slog.Info/slog.Error level

`sign` function:
```go
func sign(secret string, payload []byte) string {
    mac := hmac.New(sha256.New, []byte(secret))
    mac.Write(payload)
    return hex.EncodeToString(mac.Sum(nil))
}
```
