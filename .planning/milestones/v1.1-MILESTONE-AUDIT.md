## Design Notes

1. **`isogov-agent traits` does not show custom traits** — by design. The traits subcommand is an offline diagnostic that runs local collectors only. Custom traits require the daemon loop (server connection). Custom traits ARE visible via `gvctl clients traits`.

2. **`traverseDotPath` duplicated** in agent and CLI — deliberate. Separate binaries with no shared internal code. Implementations differ slightly but both correct (~15 lines each).

3. **Cache path discrepancy** — Plan said `/var/lib/isogov/traits/` but implementation uses `filepath.Join(dataDir, "traits")` where dataDir defaults to `/etc/isogov`. Functionally correct — configurable via `--data-dir` flag.

## Human Verification Recommended

1. End-to-end custom trait distribution with real server + agent
2. Timeout behavior with slow scripts (process group kill across OS)
