How it works

Cumulative tiers

Each band prices only the nodes in that band. A 2,500-node fleet pays $84 for the first 225, $74 for the next 750, and $64 for the remaining 1,500. Crossing a tier boundary never spikes the bill.

All features, every tier

Spanner federation, AI assistant, compliance export, RBAC, all 98 executors. A license unlocks a node count — nothing else changes.

Grace period

If you exceed your node limit: 15 days of warnings, then 15 days where only new enrollments are blocked, then shutdown. Existing nodes are never locked out.

Source-available agent

The code that runs as root on your machines is readable and auditable under the Elastic License 2.0.
