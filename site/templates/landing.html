One agent. Seven operating systems. YAML configs that anyone can read. Continuous convergence with zero database queries on the hot path.

Get Started Learn More

One Binary, Seven Platforms

Linux, macOS, FreeBSD, OpenBSD, NetBSD, illumos, Windows. Write type: service and the agent dispatches to systemd, launchd, rcctl, SMF, or sc.exe.

74 Built-in Executors

Files, packages, services, users, cron, firewall, Docker, IIS, registry, ACLs, and more. Every executor is idempotent: check before act, change only on drift.

Zero DB on Check-in

The FleetIndex holds all real-time state in memory. Agent check-ins execute with zero database queries. One server handles your entire fleet.

YAML. Not a DSL.

No custom language, no compile step, no parser quirks. A sysadmin unfamiliar with Hobnob can read a config file and understand what it does.

Offline Convergence

Agents cache signed policy bundles in LMDB. When the server is unreachable, convergence continues. Results queue locally and drain on reconnect.

Security by Default

mTLS on all traffic. ED25519 request signing. One-time bcrypt tokens. Secrets never in plaintext. No --no-ssl flag exists.

Bootstrap in 30 Seconds

curl -sSf http://server:8181/bootstrap | sudo sh

Downloads the agent, generates TLS certificates, enrolls with the server, installs the service. Under management in one command.
