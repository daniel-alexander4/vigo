Filter syntax help

Filter uses dot-path equality: os.distro=ubuntu or os.family=debian,virtual.type=kvm (comma = AND). Traits use nested keys like os.distro, hardware.arch, network.hostname.

Columns controls which trait fields appear as table columns. Comma-separated dot-paths. Default: os.distro, os.version, hardware.arch, virtual.type, uptime.days.

Common fields: os.family, os.distro, os.version, hardware.arch, hardware.cpus, memory.total_mb, virtual.type, network.hostname, kernel.version, uptime.days, docker.version
